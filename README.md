# Dungeons II Auras

Overlay for Minecraft Dungeons II. Shows artifact/potion cooldowns, buff and debuff timers, health and souls.

Download: https://github.com/KuChay1/dungeons2-auras/raw/main/Dungeons2Auras.exe

Run it once and it adds an icon to your desktop. Use that to start it, it updates itself on launch.

F8 for settings.
